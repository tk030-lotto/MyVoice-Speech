# MyVoice Speech

> **GPT-SoVITSを利用して、参照音声から日本語音声を生成するローカルWEB GUIツール**

MyVoice Speech は、オープンソースの音声合成モデル **GPT-SoVITS v2** (`gsv-v2final-pretrained`) をバックエンドとして固定利用し、参照音声と日本語テキストから音声合成（参照音声を利用した日本語音声合成）を実行・試聴・保存できるローカルGUIツールです。

---

## 1. 主な機能

- 🎙️ **参照音声指定**: ファイルドラッグ＆ドロップ・選択およびWebマイク直接録音・試聴プレビュー
- 📝 **日本語原稿入力**: テキスト入力、リアルタイム文字数カウント、テキストファイルの読込・保存・クリア
- ⚡ **音声生成・制御**: GPT-SoVITS v2 エンジンによる音声合成、進行ステータス（待機/生成中/完了/エラー）表示
- 🔊 **結果再生＆保存**: 生成音声をブラウザ上で直接再生・シーク、WAV形式でローカルへ保存
- 🔒 **ローカル動作**: 外部APIキー不要。ユーザーの音声データや原稿テキストを外部へ送信せず、ローカル環境で処理します。

## 3. 動作環境

- **OS**: Windows 10 / 11 (64bit)
- **Python**: 3.10 ~ 3.11 (推奨)
- **Node.js**: v18 以上
- **動作検証環境**: NVIDIA GPU (本ツールの開発・動作検証環境では VRAM 6GB / CUDA 11.8+ / 12.x)
- **依存ライブラリ**: PyTorch, soundfile, librosa, faster-whisper, FastAPI, React, Vite

## 4. クイックスタート (セットアップと起動)

### 4.1 🚀 一括ワンクリック起動 (推奨)

プロジェクト直下にある **`ツール起動.bat`** をダブルクリックするだけで、バックエンドAPI・フロントエンドGUIが同時に立ち上がり、ブラウザが自動的に起動します。

---

### 4.2 手動での個別起動

```bash
# 1. 依存ライブラリのインストール
pip install -r backend/requirements.txt

# 2. モデルダウンロード (初回のみ)
python scripts/download_gpt_sovits_models.py

# 3. APIサーバー起動
python backend/app.py
```
* APIサーバーが `http://localhost:8000` で起動します。

### 4.3 フロントエンド起動

```bash
# 1. フロントエンドディレクトリへ移動
cd frontend

# 2. パッケージインストール (初回のみ)
npm install

# 3. 開発サーバー起動
npm run dev
```
* ブラウザで `http://localhost:5173` にアクセスして操作します。

## 5. ⚠️【重要】検証結果と現在の限界

> ### 検証結果
>
> 本ツールは、GPT-SoVITS v2を利用した日本語音声合成をGUIから実行できるところまで実装しています。
>
> 一方で、当初想定していた**「短時間の参照音声から、本人の声に近い2～3分程度の日本語スピーチを生成する」**という用途については、現在使用しているPC環境およびGPT-SoVITS v2の設定では、実用的な品質を実現できませんでした。
>
> 実際の検証では、数秒～十数秒程度の参照音声を使用して生成を試しましたが、参照音声と生成音声の声質・発音・抑揚などが十分に一致しない場合があり、長時間の音声では品質の維持も困難でした。
>
> 参照音声の内容を文字起こししたうえで生成する方法についても検証しましたが、当初想定した本人音声の再現には十分な結果が得られませんでした。
>
> そのため、**現在の開発環境では、短時間の参照音声から長時間の本人音声を高い精度で再現する用途は実現できなかった**、というのが本プロジェクトにおける現時点での検証結果です。
>
> 本ツールは、上記の結果を含め、ローカル環境におけるAI音声合成の実用性を検証し、その結果をGUIツールとして形にした実験的なOSSです。
>
> より長い参照音声、高性能なGPU、異なるモデルや生成条件などによって結果が改善する可能性はありますが、本プロジェクトではそれらによる品質向上を保証するものではありません。
